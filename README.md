# ポイントちょきん

おてつだい・しゅくだいで ポイントを ためる、子ども向けの アプリ。iPad の「ホーム画面に追加」で使う。

- 子どもが「◯◯ した！」を押して送る → おうちのひとが **暗証番号** を入れて OK／なし を決める → OK のぶんだけ ポイントが たまる
- ごほうび（円で設定、1ポイント＝◯円で ポイントに換算）と交換すると ポイントが減る
- ポイントの もらえかた・ごほうび・暗証番号は、おうちのひとの画面で変えられる
- 送るときに「いつ やった？」（きょう／きのう／おととい／ほかの日）を選ぶ。📅 カレンダーで日ごとの内容とポイントが見られる
- OK まちは子どもが「とりけす」で消せる。OK ずみの記録は、おうちのひとの画面「📒 きろくを なおす」でだけ消せる

## しくみ

- `index.html` + `app.js` だけで動く。外部への通信なし。**記録はその iPad の localStorage の中だけ**（サーバーには送らない）
- 暗証番号は SHA-256 のハッシュだけを保存（コードにも記録にも番号そのものは残らない）
- `sw.js` が一式を保存するので、一度ひらけばオフラインでも動く。保存のときは必ずサーバーから取り直す（GitHub Pages のブラウザキャッシュ10分対策）
- 🔴 版を上げるときは `app.js` の `VERSION` と `sw.js` の `CACHE` を同じ番号にそろえる
- バックアップ: おうちのひとの画面「💾 バックアップ」で JSON を書き出し、「📂 よみこみ」で戻せる
